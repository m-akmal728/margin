# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a concern

Please report a suspected vulnerability privately through GitHub's **Report a vulnerability** feature for this repository. Do not include personal data or private research notes in a public issue.

## Data and browser security

Margin stores the library in the browser's `localStorage`; it has no account system, remote API, or server-side copy. Anyone with access to the same browser profile can access that library. Use a separate browser profile on shared devices, keep exported backups private, and only save links you trust. Links are restricted to HTTP and HTTPS, rendered as text, and opened with `noopener noreferrer`.
