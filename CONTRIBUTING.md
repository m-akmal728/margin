# Contributing

Thanks for taking an interest in Margin.

1. Fork the repository and create a focused branch (`feat/short-description` or `fix/short-description`).
2. Make a small, clear change and add or update tests for behavior you change.
3. Run `npm test` and `npm run check`.
4. Open a pull request with the reason for the change and steps to review it.

Keep the app dependency-light and local-first. Please do not add network services that transmit a user's library without making that behavior explicit and opt-in.
